Networks

  • UK Rail — every National Rail station, live Darwin data with platforms, delays and cancellations
  • Caltrain — live predictions, both directions per station
  • Switzerland — real platforms and delays across SBB
  • Ireland — Irish Rail's official realtime feed
  • Portugal — CP: Lisbon suburban, Porto urban, IC/AP intercity
  • Nottingham NET trams — timetable-based departures

How it works

  • Add as many widgets as you like — small, medium or large — each with its own station
  • Right-click a widget → Edit Train Board → search any station
  • Boards update every minute on the minute; departed trains drop off, delays turn amber, cancellations red
  • Amber-on-black in dark mode, ink-on-paper in light mode
