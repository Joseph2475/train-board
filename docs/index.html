How it works

Download and open. Notarized by Apple — no warnings, no setup. Updates install themselves.

Add widgets. Right-click your desktop → Edit Widgets → Train Board. Small, medium or large.

Pick stations. Right-click any widget → Edit Train Board → search any station. One widget per station, as many as you like.
