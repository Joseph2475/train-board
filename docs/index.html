TRAINBOARD

How it works

Download and open. Notarized by Apple, so it opens without any fuss. Updates install themselves.

Add widgets. Right-click your desktop → Edit Widgets → Train Board. Small, medium or large.

Pick stations. Right-click any widget → Edit Train Board → search any station. As many boards as you like.
